# 교특집행 CHECK

GitHub Pages에서 바로 배포할 수 있는 단일 HTML 체크리스트 사이트입니다.

## 변경사항
- `해당됨` 버튼을 선택한 상태에서 다시 클릭하면 선택이 해제됩니다.
- `해당 없음` 버튼도 동일하게 다시 클릭하면 선택이 해제됩니다.
- 선택 해제 시 해당 항목은 다시 `미점검` 상태로 돌아갑니다.

## GitHub Pages 배포
1. 이 폴더의 `index.html`을 GitHub 저장소에 업로드합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. 배포 소스를 해당 브랜치와 `/ (root)`로 설정합니다.
4. 저장 후 생성된 GitHub Pages 주소에서 사이트를 확인합니다.
